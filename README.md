# دَبّرها 🇩🇿

**مساعدك الذكي لتسيير ميزانية الأسرة الجزائرية*§*

> رتّب مصروفك، وخلّي راتبك يكفيك.

تطبيق ويب تقدّمي (PWA) يعمل بالكامل بدون إنترنت وبدون خادم خلفي، يحلّل دخل الأسرة ومصاريفها الشهرية والسنوية، ويبني خطة ميزانية ذكية تجيب فعليًا عن سؤال: **"كيف أستطيع تسيير راتبي هذا الشهر؟"**

جميع البيانات المالية تبقى مخزّنة محليًا على جهاز المستخدم فقط (`localStorage`)، ولا تُرسل إلى أي خادم.

---

## ✨ المميزات

- **معالج إعداد أولي (Onboarding)**: الدخل، الأسرة، السكن، السيارة، المصاريف الثابتة، الأهداف.
- **محرك ميزانية ذكي** (`src/utils/budgetEngine.ts`): لا نسب ثابتة عمياء، بل يحلّل الدخل ناقص الالتزامات الحقيقية.
- **تصنيف المصاريف**: 🔴 ضروري / 🟠 مهم / 🟡 قابل للتقليل / 🟢 كمالي.
- **حذف الكماليات بلحظة واحدة**: مع تحديث فوري للأرقام والرسوم البيانية.
- **"ساعدني على التوفير"**: خطة توفير مقترحة تلقائيًا حسب هدف المستخدم.
- **"هل أستطيع شراء هذا؟"**: تحليل فوري لأي عملية شراء مقترحة.
- **محاكي "ماذا لو؟"**: تأثير أي تغيير افتراضي (زيادة راتب، إلغاء اشتراك...) على الميزانية.
- **ميزانية يومية/أسبوعية** محسوبة بذكاء وليس بقسمة عمياء.
- **مصاريف سنوية وموسمية** (تأمين، رمضان، الدخول المدرسي...) موزّعة تلقائيًا على 12 شهرًا.
- **أهداف الادخار وصندوق الطوارئ** مع شريط تقدّم.
- **تقرير شهري** ومؤشر توجيهي للصحة المالية من 100.
- **تصدير/استيراد البيانات** بصيغة JSON، وحذف كامل للبيانات.
- **دعم كامل للعربية RTL**، وضع ليلي/نهاري، تصميم Mobile First.
- **PWA حقيقية**: قابلة للتثبيت على الهاتف، وتعمل Offline بالكامل بعد أول تحميل.

## ☁️ النشر على GitHub Pages (تلقائي بالكامل)

المشروع يحتوي على ملف جاهز: `.github/workflows/deploy.yml`، يقوم تلقائيًا ببناء التطبيق ونشره في كل مرة تدفع (push) فيها إلى فرع `main`. **لا حاجة لتنفيذ `npm run build` أو أي أمر يدوي بنفسك.**

1. أنشئ مستودعًا (repository) جديدًا وفارغًا على GitHub، مثلًا باسم `dabbirha`.
2. من داخل مجلد المشروع (بعد فك الضغط):
   ```bash
   git init
   git add .
   git commit -m "دبّرها - أول نسخة"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```
3. من إعدادات المستودع على GitHub: **Settings → Pages → Build and deployment → Source**، اختر **"GitHub Actions"** (وليس "Deploy from a branch").
4. بمجرد إتمام الدفع (push)، افتح تبويب **Actions** في المستودع لمتابعة عملية البناء (تستغرق حوالي دقيقة). عند اكتمالها بنجاح ✅، سيكون الموقع متاحًا على:
   `https://USERNAME.github.io/REPO_NAME/`

بعد ذلك، أي تعديل تدفعه لاحقًا إلى `main` يُنشر تلقائيًا من جديد بدون أي خطوة إضافية.

### طريقة يدوية بديلة (اختيارية)

إن رغبت بالنشر يدويًا بدلًا من GitHub Actions:
```bash
npm install
npm run build
npm install -D gh-pages
npx gh-pages -d dist
```
ثم من **Settings → Pages → Source** اختر فرع **`gh-pages`** بدلًا من GitHub Actions.

> **ملاحظة مهمة**: إعداد `base: './'` في `vite.config.ts` يجعل كل المسارات نسبية، لذلك يعمل المشروع بشكل صحيح تحت أي مسار فرعي بدون تعديل إضافي. التنقّل بين الصفحات يستخدم `HashRouter` تحديدًا لتفادي مشاكل توجيه الروابط (404) الشائعة مع React Router على GitHub Pages.

## 📲 تثبيت التطبيق على الهاتف (PWA)

- **أندرويد (Chrome)**: عند فتح الموقع ستظهر رسالة "تثبيت التطبيق" داخل التطبيق نفسه (`InstallPrompt`)، أو من قائمة المتصفح (⋮) اختر **"إضافة إلى الشاشة الرئيسية"**.
- **آيفون (Safari)**: من زر المشاركة (Share) اختر **"إضافة إلى الشاشة الرئيسية"**.

بعد التثبيت يعمل التطبيق بواجهة مستقلة بدون شريط المتصفح، ويعمل بالكامل بدون إنترنت.

## 🔧 تعديل رابط صفحة Facebook

افتح الملف:

```
src/config.ts
```

وعدّل السطر:

```ts
facebookUrl: '',
```

إلى الرابط الحقيقي لصفحتك، مثلًا:

```ts
facebookUrl: 'https://www.facebook.com/share/xxxxxxx/',
```

إن تُرك فارغًا، لن يظهر زر Facebook كرابط فعّال (تفاديًا لأي رابط وهمي). يمكن أيضًا للمستخدم النهائي تعديل هذا الرابط لاحقًا من داخل صفحة **"المزيد ← حول التطبيق"** إن رغبت في إضافة هذه الميزة مستقبلًا.

## 🎨 تعديل بيانات الهوية (Branding)

كل بيانات الهوية موجودة في ملف واحد: `src/config.ts`

```ts
export const APP_CONFIG = {
  appName: 'دَبّرها',
  appTagline: 'مساعدك الذكي لتسيير ميزانية الأسرة الجزائرية',
  developerName: 'prof.i3lam_ali',
  instagramUrl: 'https://www.instagram.com/prof.i3lam_ali/',
  facebookUrl: '',
};
```

لتغيير الألوان أو الخطوط، عدّل `tailwind.config.js` (الألوان `ink` / `sand` / `clay`) و`index.html` (الخطوط من Google Fonts).

## 📁 هيكل المشروع

```
src/
  components/     مكوّنات مشتركة (BottomNav, PageHeader, SocialFooter...)
  pages/          كل صفحة من صفحات التطبيق
  context/        إدارة الحالة العامة (AppDataContext, ToastContext)
  utils/          الخوارزميات المالية (budgetEngine, savingsEngine, financialScore...)
  data/           بيانات تجريبية (Demo Mode)
  services/       aiService.ts (جاهز لدمج AI مستقبلًا، اختياري بالكامل)
  types/          تعريفات TypeScript
  config.ts       إعدادات الهوية والروابط
public/
  icons/          أيقونات PWA (192, 512, maskable)
  manifest يُبنى تلقائيًا عبر vite-plugin-pwa
```
